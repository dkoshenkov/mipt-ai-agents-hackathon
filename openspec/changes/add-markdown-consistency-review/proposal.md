# Proposal

## Why

Сотруднику закупок нужно увидеть, какие требования одного ТЗ несовместимы, где они записаны и что можно исправить. В исходном примере «500 кг» встречается в нескольких местах, а единица для значения 300 указана в соседней ячейке. Ссылка на произвольное совпадение способна привести к правке другого требования.

## What Changes

- Добавить сценарий проверки внутренней согласованности одного Markdown-документа. Входом служит Markdown произвольной структуры. Требования могут быть изложены сплошным текстом, списком или таблицей. Связь с DOCX/PDF возможна у вызывающей стороны, если у неё есть карта конвертации.
- Использовать библиотечный контракт [typed-review-stage](../../specs/typed-review-stage/spec.md) для всех запросов модели. Чтение каталога использует отдельный транспорт с проверкой происхождения данных и собственным лимитом обращений.
- Проверять числовые и смысловые гипотезы по адресуемым фрагментам, учитывать объект, этап, единицы и оговорки. Выводить подтверждённые проблемы и вопросы для уточнения, показывать пропуски обработки.
- Устанавливать приоритет спорного значения в пределах позиции, свойства и условий. Показывать основание выбора или задавать заказчику вопрос с вариантами и исходными цитатами. Предлагать конкретную замену, когда известно основание нового значения. Проверять набор правок на копии Markdown.
- Сравнить сценарий с прямой проверкой всего документа на одинаковой модели и размеченных случаях из двух предметных областей.

- Проверять конкретные ссылки на ГОСТ в ТЗ и их применимость к названному объекту, этапу или методу. Возвращать источники для каждого вывода.

## Capabilities

### New Capabilities

- `standard-reference-review` — поиск ошибок в обозначениях и названиях стандартов, проверка существования, применимости и предложенной замены по источнику.

- `markdown-consistency-review` — проверка внутренней согласованности Markdown, доказательства, предметные решения или технические причины остановки, проверка предложенных исправлений и измерение качества поиска.

## Impact

Один Rust crate, модули `core` и `runtime`, новый сценарий рядом с `review_223`, локальный пример и набор проверочных случаев. Появляется ограниченное чтение официального каталога и локальных снимков для воспроизводимой проверки. Внешний вызов возможен для данных с разрешённым статусом. Ветка возвращает результат для общей сводки. Выбор правового основания и слияние исправлений разных веток принадлежат общей системе.
