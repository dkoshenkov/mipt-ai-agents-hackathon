# Proposal

## Why

Участникам команды нужен общий способ подключать новые проверки Markdown и собирать их в сценарии на Rust. Первым потребителем библиотеки станет ветка по 223-ФЗ с конкурентными запросами к Grok и одним вызовом критика.

## What Changes

- Принять Markdown и список включенных проверок. Запустить независимые вызовы Grok конкурентно через xAI API. Состав проверок определяется при запуске.
- Собрать результаты всех агентов в одном месте, включая ошибки, и один раз вызвать критика по собранным данным.
- Дать автору сценария отдельные операции запуска, агрегации и вызова критика. Вернуть собранные находки и исходы проверок как при заключении критика, так и при его ошибке.
- По умолчанию записывать ход выполнения в структурированный журнал.

## Capabilities

### New Capabilities

- `parallel-223-review` — параллельный запуск агентов, агрегация и заключение критика по этой ветке проверки.

## Impact

В проекте появится один библиотечный crate с модулями `core` и `runtime`. Ветку по 223-ФЗ команда пишет как обычную `async fn` и может запустить ее параллельно с другими ветками. Разработка остальных веток и общего заключения по ТЗ относится к последующим изменениям.
